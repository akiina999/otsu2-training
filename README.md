# 危険物乙2トレーニング

危険物取扱者 乙種第2類の個人学習用ブラウザアプリです。

## PCでの起動方法

1. このリポジトリをダウンロードまたは clone します。
2. `index.html` をダブルクリックします。
3. Chrome または Edge でオフライン動作します。

## iPhoneでの利用

GitHub Pagesを有効にすると、Safariからアクセスできます。

1. GitHubのリポジトリ画面で `Settings` を開く
2. `Pages` を開く
3. `Build and deployment` のSourceを `Deploy from a branch` にする
4. Branchを `main`、フォルダを `/ (root)` にして保存
5. 表示された公開URLをiPhoneのSafariで開く

Safariの共有メニューから「ホーム画面に追加」を選ぶと、アプリアイコンから起動できます。

復習候補は端末・ブラウザごとのlocalStorageへ保存されます。PCとiPhoneの復習データは現時点では同期されません。

## 現在の機能

- 本試験に合わせた五肢択一
- 10問・20問・30問・50問から出題数を選択
- 問題ごとに「法令」「基礎物理・化学」「乙2の性質・消火」の区分を表示
- PCではキーボードの `1`〜`5` で回答
- `W` で「わからない」
- 回答直後の簡易解説・詳細説明
- 不正解・わからない問題の復習候補への自動登録
- 正解したが不安な問題の手動登録
- 復習候補の選択、削除、再出題
- チェックONの問題を削除
- チェックOFFの問題を一括削除
- 復習で正解した問題のチェックを自動で外す
- 最後の問題後はダイアログを挟まずトップへ戻る
- iPhone縦画面向けレスポンシブ表示
- ホーム画面追加用Web App Manifest

## 問題データ

現在は第2類の性質、火災予防、消火方法、指定数量、法令基礎を中心に50問収録しています。

問題は、消防試験研究センターの公開問題の出題傾向、消防法別表第一、危険物の規制に関する政令、総務省消防庁の公開資料を参考に、個人学習用のオリジナル問題として再構成しています。

各問題には次の情報を持たせています。

- 問題ID
- 試験区分
- 分野
- タグ
- 重要度
- 五つの選択肢
- 正答
- 簡易解説
- 詳細説明
- 参考情報

## ファイル構成

- `index.html`：画面
- `app.js`：学習・復習ロジック
- `questions-1.js`〜`questions-5.js`：問題データ
- `manifest.webmanifest`：ホーム画面追加用設定
- `icon.svg`：アプリアイコン

外部サーバーは不要です。ローカルの `file://` で確実に動かすため、問題データはJSONの直接読込ではなくJavaScriptファイルとして分割しています。
