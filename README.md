# 危険物乙2トレーニング

危険物取扱者 乙種第2類の個人学習用ブラウザアプリです。

## 起動方法

1. このリポジトリをダウンロードまたは clone します。
2. `index.html` をダブルクリックします。
3. Chrome または Edge でオフライン動作します。

## 現在の機能

- 本試験に合わせた五肢択一
- 10問・20問・30問から出題数を選択
- キーボードの `1`〜`5` で回答
- `W` で「わからない」
- 回答直後の簡易解説・詳細説明
- 不正解・わからない問題の復習候補への自動登録
- 正解したが不安な問題の手動登録
- 復習候補の選択、削除、再出題
- 復習で正解した問題のチェックを自動で外す

## 問題データ

現在は第2類の性質、火災予防、消火方法、指定数量を中心に30問収録しています。

問題は、消防試験研究センターの公開問題の出題傾向、消防法別表第一、総務省消防庁の公開資料を参考に、個人学習用のオリジナル問題として再構成しています。

各問題には次の情報を持たせています。

- 問題ID
- 分野
- タグ
- 重要度
- 五つの選択肢
- 正答
- 簡易解説
- 詳細説明
- 参考情報

## ファイル構成

- `index.html`：画面
- `app.js`：学習・復習ロジック
- `questions-1.js`〜`questions-3.js`：問題データ

外部サーバーは不要です。ローカルの `file://` で確実に動かすため、問題データはJSONの直接読込ではなくJavaScriptファイルとして分割しています。
